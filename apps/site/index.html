不打断你手上的事

不用找数据线，不用给自己发邮件，也不用在电脑上登聊天软件。

复制就到

手机上发过来的字，自动进电脑剪贴板。在任何软件里按 Ctrl+V 就粘出来。

照片原图存好

手机照片原图送到电脑，自动存进文件夹，还能直接拖进网页、聊天框。

电脑也能发手机

网页上选中文字或图片，右键「发到手机」。电脑上复制的长文字也能一键送到手机。

不经过服务器

同一个 Wi-Fi 下，手机直接送到电脑。你传的内容不会上传到任何地方。

常见问题

手机要装 App 吗？

不用。手机上就是一个网页，扫码打开就能用。想用得顺手，可以把它「添加到主屏幕」，像 App 一样一点就开。

我传的东西安全吗？

手机和电脑在同一个 Wi-Fi 下直接连，内容不经过任何服务器。配对用的暗号藏在二维码里，别人不扫你的码就连不上。

手机和电脑不在同一个 Wi-Fi 能用吗？

现在需要连同一个 Wi-Fi，比如家里或办公室。不同网络之间互传，后面会加上。

支持哪些手机和电脑？

手机：iPhone 和安卓都行，用浏览器打开。电脑：Windows 上的 Chrome 或 Edge 浏览器。

电脑关掉插件或手机锁屏了，发的东西会丢吗？

不会。没送到的会先留着，两边再连上时自动补发。
